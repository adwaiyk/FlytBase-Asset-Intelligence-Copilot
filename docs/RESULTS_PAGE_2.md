## Edge Case Handling & Architectural Resilience

1. **New Well Type Ingestion (`T500` ESP Lift):**
   - The engine parsed `fleet/well-types/T500.md` dynamically on startup without code modifications, extracting the **$25.0^\circ\text{C}$** producing limit, $95^\circ\text{C}$ alarm, and 14-day 3-drop early warning policy.
2. **Deterministic Precedence (OPS-3):**
   - The hybrid architecture avoids LLM guesswork by evaluating operator restart/shut-in timestamps against weekly drone flight timestamps directly in DuckDB before passing the state to Gemma 4.
3. **Multi-User Privacy vs. Shared Memory Isolation:**
   - Private formatting preferences and conversational recalls remain partitioned by `user_id` in SQLite, while operational facts (such as pump recall swaps) broadcast globally with full author attribution (`FB-0001` by Nathan Pierce, `FB-0002` by Olivia Grant).
