# FlytBase-Asset-Intelligence-Copilot

An Asset Intelligence Copilot for the FlytBase challenge at Hacktoberfest Hack Day Pune (17 Oct 2026): a chat assistant that answers operators' plain-English questions about oil wells, correctly and with evidence, powered by Gemma 4.

- System design and build plan: [`docs/SYSTEM_DESIGN.md`](docs/SYSTEM_DESIGN.md)
- Deterministic reference check of the example answers: `python scripts/golden_check.py <path-to-dataset-repo>`
- Dataset: [FlytBaseAILabs/flytbase-ahc-swe-asset-intelligence-dataset](https://github.com/FlytBaseAILabs/flytbase-ahc-swe-asset-intelligence-dataset)
